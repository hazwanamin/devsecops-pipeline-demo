\# DevSecOps Pipeline Demo



A CI/CD security pipeline built with GitHub Actions demonstrating 

automated security checks on every push.



\## Pipeline Jobs



| Tool | Type | Purpose |

|---|---|---|

| Semgrep | SAST | Scans source code for insecure patterns |

| Gitleaks | Secrets | Detects hardcoded credentials in code |
